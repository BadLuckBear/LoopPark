# 车辆材质调节说明

打开 Unity 菜单 **LoopPark → 车辆外观调节（支持运行中）**。选择车色后，每个部件都有材质球和“编辑”按钮。点击“编辑”在 Inspector 中调整材质，运行中的车辆会直接显示修改。调好后点“保存当前外观配置”。

## 材质存放位置

`Assets/LoopPark/Resources/Model/Materials/Appearances/`

每种车色一组独立材质，例如 `Color02_Paint.mat` 是蓝色车的车漆，`Color02_Windows.mat` 是蓝色车的车窗。`Hidden_` 开头的是问号车，不能拿正常车色的材质替换，避免泄露隐藏颜色。

| 部件 | 文件后缀 | 可调整内容 |
| --- | --- | --- |
| 车漆、后视镜 | Paint | 颜色、贴图、高光颜色、光滑度 |
| 车窗 | Windows | 颜色、贴图、独立高光与光滑度 |
| 窗框、黑色结构 | Frames | 颜色、独立高光与光滑度 |
| 饰条 | Trim | 颜色、贴图、表面质感 |
| 前铲内部、下摆 | Splitter | 颜色、贴图、表面质感 |
| 前灯 | Headlights | 颜色、高光、发光颜色及贴图 |
| 灯条 | LightStrip | 颜色、高光、独立发光颜色及贴图 |
| 尾灯 | Taillights | 颜色、高光、独立发光颜色及贴图 |
| 轮毂 | Wheels | 颜色、高光、光滑度 |
| 轮胎 | Tires | 颜色、法线、粗糙表面质感 |

所有材质均使用 **LoopPark/Layered Car** Shader。它还支持法线贴图、法线强度、环境遮蔽贴图和遮蔽强度。颜色贴图与材质颜色相乘；希望保留贴图原色时将材质颜色设为白色。环境遮蔽读取贴图 G 通道。车辆保持不透明，车窗依靠颜色和高光表现，不支持透明玻璃。发光会提亮材质；屏幕上的光晕还需要后处理支持。

## 保存、共享与回退

材质优先于旧调色参数。旧面板的“车身颜色”和整车光泽只影响未指定独立材质的部件。直接调整材质球，运行时代码不会覆盖其颜色、贴图、高光或发光；代码只写车辆深度用于遮挡排序。

把同一材质拖到两种车色会让它们共享外观。需要独立效果时，先在 Project 窗口复制材质，再绑定到目标车色。清空某个材质引用可使用旧参数回退；再次打开工程不会自动补回主动清空的引用。

首次升级会自动创建并绑定 15 色与问号车共 160 个材质球。菜单 **LoopPark → 生成或补齐车辆独立材质** 可补齐空引用，不覆盖已有材质的参数。材质和 LoopParkSkin.asset 都需要随工程一起交付。

## 检查入口

**LoopPark → 验证独立车辆材质（无需运行）**：验证 15 色及问号车的全部网格绑定、从旧配置切换到新材质时清除属性覆盖，并检查颜色、高光、发光不被运行时代码改写，深度属性仍然存在。

**LoopPark → 验证车辆外观与实时调节**：在运行关卡时验证外观刷新和缩放。

**LoopPark → 渲染车模型预览**：输出 `Logs/car_preview.png`，用于查看 15 色材质的一致性；最终验收以游戏内灯光和实际显示尺寸为准。
